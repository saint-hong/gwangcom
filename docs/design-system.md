## 1. 레이아웃

캡처는 상단 헤더가 없는 3단 구조다.

```
┌─────────────┬──────────────────────────┬───┬──────────────────┐
│ 왼쪽 사이드바 │ 본문 (좌우 세로 테두리)       │   │ 오른쪽 컬럼         │
│ 275px       │ 600px                    │30 │ 350px            │
│ 로고         │ [추천|AI|Space…] 글자 탭     │   │ (검색창)           │
│ 메뉴(아이콘+이름)│ 카드 / 카드 / 카드 …         │   │ 카드: 이번 주 질문   │
│ 더 보기       │                          │   │ 카드: 인기 상상      │
│ [가입하기]    │                          │   │ 카드: 추천 Dreamer   │
│ [로그인]      │                          │   │ 푸터               │
└─────────────┴──────────────────────────┴───┴──────────────────┘
```

| 폭 | 레이아웃 |
|---|---|
| 1280px 이상 | 275 · 600 · 30+350 |
| 1100~1280px | 오른쪽 컬럼을 290~320px로 줄임 |
| 900~1100px | 오른쪽 컬럼 숨김, 푸터는 본문 아래로 |
| 700~900px | 왼쪽 사이드바를 아이콘만(88px)으로 접음, 가입·로그인은 둥근 아이콘 버튼 |
| 700px 미만 | 사이드바 숨김 → 상단 바(로고 · 다크 모드 · 상상하기 · 가입하기) + 하단 탭바(아이콘 5개) |

### 로고 위치
- 글자 로고의 첫 글자 **I 는 파비콘의 I 와 같은 모양**(위·아래 가로획)으로 그려 소문자 l 과 구분하고 파비콘과 연결한다.
- 넓은 사이드바: **글자 로고만**. I 의 앞을 아래 **메뉴 아이콘의 앞(그려진 선)**과 맞춘다 — 왼쪽 여백 14px (2026-11-10 사용자 지정). 로고 영역 높이 64px
- 사이드바 "인기 상상" 아이콘 = 번개(lucide `Zap`, Thunder 와 같은 모양). 모바일 하단 탭 "인기"도 같음 (2026-11-10, 불꽃에서 변경)
- 접힌 사이드바(700~900px): 마크(파비콘과 같은 보라 정사각형 + I)만
- 모바일 상단 바: 글자 로고

### 파비콘 (브라우저 탭 아이콘) · 페이지 제목
- `frontend/public/favicon.svg` — **보라(#6d28d9) 둥근 정사각형 + 흰 대문자 I** (하이젠버그 파비콘 형식: 색 정사각형 + 흰 머리글자)
  - I 는 위·아래 가로획이 있는 모양으로 그려 16px 에서도 l · | 와 구분되게 함
- 페이지 제목(탭 글자) · 설명: **Imagine - 당신의 상상이 세상을 바꿉니다** (`frontend/index.html`)
- 접힌 사이드바(700~900px)의 로고 마크도 같은 모양

### 액션 바 (2026-11-09 사용자 지정)
```
[⚡ 14] [≈ 3] [💬 5] [🥣 2]   ……   [🔖] [⇪]
 Thunder Wave  댓글   Shake it        북마크 공유
```
- 왼쪽 4개(Thunder · Wave · 댓글 · Shake it)는 같은 간격, 북마크 · 공유는 오른쪽 끝.
- 모두 **배경 없는 선 아이콘 + 숫자**. 글자·툴팁 없음(스크린리더용 이름 `aria-label` 만).
- 마우스를 올려도 **색·배경은 바뀌지 않고 움직임만** 있다 (2026-11-10, 통일감을 위해). 색은 눌러서 켜졌을 때만 바뀐다.
- 마우스를 올렸을 때 움직임

  | 버튼 | 켜짐 색 | 움직임 |
  |---|---|---|
  | Thunder(번개, lucide `Zap`) | `--color-thunder` | 번쩍번쩍 깜빡이며 살짝 흔들림 (누르면 내리꽂히듯 커지며 빛이 번지고 노랗게 채워짐) |
  | Wave | `--color-wave` | 파도가 앞으로 밀려왔다 물러나며 넘실댐 (누르면 한 번 크게 솟구치고 파란색으로 켜짐) |
  | 댓글 | — | 말하듯 톡톡 기울어짐 |
  | Shake it | — | **숟가락·젓가락이 번갈아 들썩이고 별 5개가 하나씩 깜빡임** |
